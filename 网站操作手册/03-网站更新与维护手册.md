## 二、改页面后的发布流程(核心流程,五步)

网站页面(样式/文案/图片/布局)的改动都在**源代码**里,改完后需要"构建 → 打包 → 上传 → 解压",网站才会更新。

### 第 1 步:在项目电脑上构建(一条命令)

在装好项目代码的电脑上(项目目录 `D:\CC\1_madecare\project_SourceCode\official`),打开 cmd 执行:

```
npm run build:server
```

这一条命令自动完成:复制手机版文件 + 设置无路径前缀 + 构建。等几分钟跑完。

### 第 2 步:打包

把 `public` 文件夹里的**全部内容**打成 zip,命名为 `website.zip`。
注意:打包的是 public 里面的文件本身,不是把 public 这个文件夹打进去。

### 第 3 步:上传到服务器

```
scp -P 11162 website.zip root@47.104.163.193:/tmp/
```

(也可以用 WinSCP 拖拽上传,端口填 11162)

### 第 4 步:服务器上覆盖解压

```
ssh -p 11162 root@47.104.163.193
rm -rf /var/www/madecare && mkdir -p /var/www/madecare && unzip -o /tmp/website.zip -d /var/www/madecare && chmod -R 755 /var/www/madecare && ls -la /var/www/madecare/index.html
```

**chmod 那条必须要有**——Windows 打包的文件解压后只有 root 能读,漏了会报 403。

### 第 5 步:验证

浏览器 `Ctrl+F5` 打开预览地址(或正式网址),按文末"验证清单"逐项检查。

## 二点五、两个网址的区别:测试看效果 vs 正式上线

很多人会搞混"改完在哪看"和"怎么才算上线",这里一次说清:

### 1. 测试/看效果用哪个网址?

**每次发布前,先看预览地址(测试地址)**:

```
http://47.104.163.193:8081/
```

- 电脑版、手机版、中英文、动态数据,这个地址上的一切都和正式网站**完全相同**(同一份文件)
- 改完页面 → 构建打包上传 → **先在这个地址上检查**,确认没问题
- 公司内部同事想提前看效果,也发这个地址
- 备案未完成期间,这个地址是**唯一**能访问新网站的方式

### 2. 想要正式上线到官网(www.madecare.com)怎么办?

正式域名上线有**四个前提条件,缺一不可**,全部满足才开放:

| 步骤 | 做什么 | 在哪做 |
|------|--------|--------|
| ① 备案通过 | ICP 备案审核通过(通常 2~3 周) | 阿里云控制台查询状态 |
| ② 域名解析 | www 和 @ 两条 A 记录指向 47.104.163.193 | 阿里云控制台 → 域名解析 |
| ③ 停用旧官网配置 | 旧官网(www.madecare.com,80 端口)让位,将其配置改名停用(如把旧站 conf 改名加 .bak 后缀) | 服务器 /etc/nginx/conf.d/ |
| ④ 改新站 Nginx 配置 | madecare.conf 里 `listen 8081` 改 `listen 80`、`server_name` 改成 www.madecare.com | 服务器(方法见"三") |
| ⑤ 重新加载配置 | `nginx -t` 检查 → `nginx -s reload` 生效 | 服务器 |

**上线当天建议的完整顺序**:

1. 确认备案状态显示"已通过"
2. 添加域名解析(两条 A 记录)
3. 等解析生效(几分钟到几小时,期间仍可继续用预览地址)
4. 停用旧官网配置:在服务器执行 `mv /etc/nginx/conf.d/旧官网配置文件名 /etc/nginx/conf.d/旧官网配置文件名.bak`(旧官网文件具体名字先 `ls /etc/nginx/conf.d/` 确认)
5. 改新站 madecare.conf(8081→80,server_name→www.madecare.com)
6. `nginx -t` 检查、`nginx -s reload` 生效
7. 用手机流量(不用公司 WiFi,避免内网缓存干扰)打开 `http://www.madecare.com/` 验证
8. 验证通过 = 正式上线完成,新官网替换旧官网;预览地址 8081 保留,以后作为测试通道继续使用

> **重要提醒**:www.madecare.com 这个域名目前在 80 端口上跑着**旧官网**。新旧两个站不能同时占用 80 端口的同一域名,所以正式上线 = 用新站**替换**旧官网,旧站配置必须先停用。切换前请确认公司已同意旧官网下线。

> 正式上线后,每次改页面仍建议先在 8081 预览确认,再同步到正式站(两边读的是同一份网站文件,上传后同时更新)。

## 三、Nginx 配置(已建好,备案通过后只需改一处)

当前配置 `/etc/nginx/conf.d/madecare.conf`(备案期间用 8081 端口):

```nginx
server {
    listen 8081;
    server_name 47.104.163.193;

    root /var/www/madecare;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location = /news-data.json {
        add_header Cache-Control "no-cache";
    }
}
```

**备案通过后正式上线**,把 `listen 8081;` 改为 `listen 80;`、`server_name` 换成 `www.madecare.com madecare.com`,然后:

```bash
nginx -t
nginx -s reload
```

改配置用 `vi`(按 `i` 编辑、`Esc`、`:wq` 保存)。

> 注意:新站上线接 www.madecare.com 时,**旧官网的 80 端口配置必须先停用**(见"二点五"第 ④ 步),否则新旧站同域名同端口会冲突。

## 四、域名与备案

1. **ICP 备案**(前提):域名放在国内服务器必须完成备案,否则 80 端口被拦截。在阿里云控制台 beian.aliyun.com 走"新增网站"流程(公司已有主体,复用即可),通常 2~3 周。
2. **域名解析**(备案通过后做):阿里云控制台 → 域名 → 添加两条 A 记录指向 `47.104.163.193`:

| 记录类型 | 主机记录 | 记录值 |
|---------|---------|--------|
| A | www | 47.104.163.193 |
| A | @ | 47.104.163.193 |

3. **备案通过前不要配解析**(未备案域名解析到国内服务器可能被检测拦截)。

## 七、常见问题

**Q: 打开 403?**
服务器上执行 `chmod -R 755 /var/www/madecare`(第 4 步漏了权限命令)。

**Q: 打开 404?**
解压后文件多套了一层文件夹;或 Nginx root 没指向文件实际目录。检查 `/var/www/madecare/` 下是否直接是 index.html。

**Q: 8081 打不开?**
检查阿里云安全组是否放行 8081(入方向,TCP,来源 0.0.0.0/0)。

**Q: 域名解析了但打不开?**
十有八九是备案未完成(国内服务器拦截),在阿里云查备案状态。

**Q: 想上 HTTPS?**
备案通过、解析生效后,可申请免费证书(无宝塔用 certbot,或阿里云 SSL 证书配 Nginx)。

**Q: 以后网站又改了怎么办?**
重复第二部分 1~5 步。提醒:重新部署会覆盖服务器上的 news-data.json,部署前记得把最新动态数据放进包里(或部署后让动态负责人重新保存)。

## 八、附:手机版与电脑版的关系

- 手机版是独立的静态页面(项目 `mobile/views/` 目录),`npm run build:server` 会自动把它打进包
- 设备自动跳转:手机打开电脑版地址会自动跳手机版首页;电脑打开手机版地址会自动跳回电脑版
- 中英文两站:手机版有中文站和英文站两套页面,修改要两边同步;电脑版中英文共用一套页面代码,文案在 `src/intl/zh.json` 与 `src/intl/en.json`
