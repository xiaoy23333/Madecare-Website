# 冀德远健官网 · 发布动态操作手册

> 适用范围:在公司官网(www.madecare.com)的"远健动态"里发布、删除、修改新闻内容。
> **不需要懂代码**,全部鼠标操作,改完立即生效。
> 正式网址:http://www.madecare.com/ (备案完成前使用内部预览地址 http://47.104.163.193:8081/ )

---

## 一、原理一句话

"远健动态"的所有内容都来自服务器上的一个数据文件:

```
/var/www/madecare/news-data.json
```

**改这个文件 = 改网站内容**。保存后刷新网页,电脑版、手机版、中英文自动同步更新,不用重启服务器。

---

## 二、准备工作(只做一次)

### 1. 安装 WinSCP(免费的传文件工具)

浏览器打开 `https://winscp.net/eng/download.php`,下载并安装(一路"下一步")。

### 2. 配置登录(第一次连接)

打开 WinSCP,登录窗口按下面填:

| 项目 | 填写内容 |
|------|---------|
| 文件协议 | SFTP(默认) |
| 主机名 | 47.104.163.193 |
| 端口号 | 11162 |
| 用户名 | root |
| 密码 | 服务器密码(向维护人索取) |

点"保存"勾选"保存密码",以后双击即可登录。

## 三、发布一条新动态

### 第 1 步:连接服务器

双击已保存的会话登录。右侧窗口就是服务器文件。

### 第 2 步:打开数据文件

右侧窗口按路径依次双击进入文件夹,找到 `news-data.json`:

```
/var/www/madecare/news-data.json
```

**先双击打开它,把全部内容复制到记事本存一份(备份,改错了能恢复)。**

### 第 3 步:粘贴新动态模板

数据文件里,"zh" 是中文动态,"en" 是英文动态。在 `"zh": [` 的**下一行**(第一条动态之前)粘贴下面模板,再改成真实内容:

```json
{
  "id": "news20240301",
  "title": "动态标题",
  "time": "2024-03-01",
  "publisher": "冀德远健",
  "cnt": "一句话简介,显示在列表页,建议60字以内",
  "src": "",
  "body": [
    { "t": "txt", "v": "正文第一段。" },
    { "t": "title", "v": "小标题(可选)" },
    { "t": "img", "v": "图片地址(可选)" },
    { "t": "txt", "v": "正文第二段。" }
  ]
},
```

**注意**:条目之间用英文逗号 `,` 隔开;最后一条后面不要加逗号。

### 第 4 步:保存上传

按 `Ctrl+S` 保存,WinSCP 弹出"是否上传修改后的文件",点 **"是"**。

**完成!** 打开网站(电脑/手机)刷新即可看到新动态。

---

## 四、各字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 每条唯一代号,不能重复、不能有空格。建议"news+日期",如 news20240301 |
| title | 是 | 动态标题 |
| time | 是 | 发布日期,格式 年-月-日 |
| publisher | 否 | 发布者,默认 冀德远健 |
| cnt | 是 | 一句话简介,显示在列表页 |
| src | 否 | 封面图地址。**没有图就写 ""(两个英文引号)** |
| body | 是 | 正文,由一段段组成,段与段用英文逗号分隔 |

### body 的四种段落类型

- `{ "t": "txt", "v": "文字内容" }` — 正文段落
- `{ "t": "title", "v": "小标题文字" }` — 加粗小标题(可选)
- `{ "t": "img", "v": "图片地址" }` — 一张图(可选)
- `{ "t": "video", "v": "视频地址" }` — 一个视频(可选)

---

## 五、图片怎么填

- **上传到公司服务器**(推荐):用 WinSCP 把图片文件拖到右侧 `/var/www/madecare/news-imgs/` 文件夹里,数据里填相对路径:

```
"src": "news-imgs/我的图片.jpg"
如果一个图片在news-imgs文件夹下imgs文件夹下News文件夹里，那他的相对地址就是news-imgs/imgs/News/图片名称.格式
```

- **用外链图**:填完整网址,如 `https://图片地址.jpg`(注意对方网站可能防盗链,不显示时改用上一种方式)
- **不带图**:`src` 写 `""`,正文里不放 img 段落,完全没问题

---

## 六、删除一条动态

找到该条的 `{ "id": "xxx", ... }` 整段(从 `{` 到对应的 `}`),连同它前后的一个逗号一起删掉,保存上传即可。

## 七、发布后验证

1. 电脑打开官网 → 首页底部"远健动态"轮播 → 看新动态是否出现
2. 进入"远健动态"列表页 → 点新动态 → 看详情
3. 手机打开官网 → "远健动态" → 同样检查
4. 没变化按 `Ctrl+F5` 强刷(手机清缓存或开无痕窗口)

---

## 八、重要提醒(必读)

1. **每次改前先备份**:把文件内容复制存一份。改错了把备份粘贴回来保存即可恢复。

2. **网站更新代码会覆盖数据**:公司更新网站(改页面样式等)时,会重新上传整包文件,**用包里的旧数据覆盖掉你改过的动态内容**。遇到网站更新,更新后把备份的动态内容重新保存回服务器;或者提前把最新动态内容发给维护人,让维护人打进包里。

3. **格式改错导致动态区空白**:最常见是逗号漏加、引号没成对。把备份内容贴回来保存即可。也可以把文件内容复制到 `https://www.json.cn` 在线校验,它会指出第几行有问题。

---

## 九、常见问题

**Q: 保存后网站没变化?**
数据文件已配置不缓存,正常立即生效。先 `Ctrl+F5` 强刷;手机浏览器缓存顽固,用无痕窗口试。

**Q: 电脑版有、手机版没有?**
两边读的是同一个文件,强刷即可同步;确认不是打开了旧的标签页。

**Q: 图片不显示?**
检查图片地址:相对路径要求文件确实传到了服务器 `news-imgs/` 目录;外链图可能被防盗链拦截。

**Q: WinSCP 连不上服务器?**
检查主机名(47.104.163.193)、端口(11162)、密码是否输对;还不行就问维护人确认服务器是否在正常运行。
